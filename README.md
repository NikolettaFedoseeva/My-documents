# 🎓 LERN — Инновационная Образовательная Экосистема

> **Современная платформа для глубокого инженерного обучения, интерактивной практики и тренировки долговременной памяти.**  
> Построена на базе **Vue 3**, **TypeScript**, методологии **Feature-Sliced Design (FSD)**, микрофронтендной архитектуры и облачного бэкенда на **Supabase PostgreSQL**.

---

## 🌟 Философия и Концепция проекта

**LERN** объединяет в себе три ключевых образовательных измерения:
1. 📜 **Академическая глубина (Bookish Codex)** — оформление учебных материалов в эстетике благородного пергаментного справочника с акцентом на концентрированную типографику, цитаты, структурированный код и интерактивные заметки на полях.
2. 🧠 **Когнитивная наука (Active Recall & Spaced Repetition)** — кинематографичный 3D-тренажер колоды знаний с процедурным звуковым сопровождением (Web Audio API), комбо-сериями и научно обоснованным интервальным повторением.
3. 💻 **Практика первого класса (Hands-on Practice)** — встроенная веб-песочница кода, система сдачи лабораторных работ на ревью менторам и конструктор курсов для авторов с Live Preview.

## 🚀 Что мы реализовали: Полный обзор модулей

### 1. 📖 Пергаментный Справочник Знаний («Bookish Codex»)
- **Иерархическое дерево дисциплин**: каскадный сайдбар с нумерацией модулей (`01 ➔ 02 ➔ 03`), индикацией статусов глав (`✓ Пройдено`, `🔥 В процессе`, `🔒 Заблокировано`), поиском в реальном времени и мобильным Drawer-режимом.
- **Пергаментный лист статьи**:
  - Типографика с поддержкой врезок-callout (`💡 Подсказка`, `⚠️ Внимание`, `ℹ️ Важно`).
  - Блоки кода `DocCodeBlock` с подсветкой синтаксиса, быстрым копированием и прямой кнопкой запуска в песочнице.
  - Пергаментные закладки страниц (`Bookmark`) с моментальной фиксацией.
  - Интерактивные **заметки на полях статьи (Margin Notes)** с выбором цветных маркеров (`amber`, `cyan`, `emerald`, `purple`).
  - Пагинация между главами (`← Назад / Далее →`) и фиксация прогресса (+50 XP).

### 2. 🧠 Полноэкранный 3D-Тренажёр памяти («Active Recall Deck Trainer»)
- **Кинематографичный Focus Mode**: полноэкранный темный оверлей со светящимися градиентными сферами.
- **3D-карточка с поворотом на 180°** (`rotateY`): лицевая сторона (вопрос, подсказка) и оборот (ответ, самооценка).
- **Оценка памяти и комбо-стрики**:
  - `🔴 Повторить` (отправка в конец колоды), `🟡 Сомневаюсь` (+10 XP), `🟢 Знаю` (+25 XP).
  - Множитель серий комбо (`🔥 x2..x5+ Combo`) с нарастающим бонусом к опыту.
- **Синтезатор звука Web Audio API**:
  - Процедурный синтез без внешних аудио-файлов (шелестящий щелчок переворота карты, хрустальный пинг подсказки, аккорды успеха и победный перезвон завершения колоды C5-E5-G5-B5-C6).
- **Навигация с клавиатуры**: `Пробел` / `Enter` (переворот), `1 / 2 / 3` (оценка), `H` (подсказка), `Esc` (выход).
- **Экран итогов тренировки**: детальная аналитика сессии, начисленный опыт и режим работы над ошибками.

### 3. 💻 Интерактивная In-Browser Песочница Кода («Code Playground»)
- **Запуск JavaScript & TypeScript в 1 клик** прямо из любого блока кода в статье или конструкторе автора.
- **Движок выполнения (`useCodeRunner`)**:
  - Регулярный стриппер типов TypeScript `stripTsTypes` (интерфейсы, алиасы типов, дженерики, аннотации типов).
  - Изолированная среда выполнения с перехватом `console.log`, `info`, `warn`, `error`.
  - Замер времени выполнения в миллисекундах (`performance.now()`) и обработка возвращаемых значений выражений (`← return`).
- **Модальное окно со сплит-панелью**:
  - Редактор с номерами строк, поддержкой отступов по `Tab` и запуском по `Ctrl + Enter`.
  - Форматированный терминал вывода с цветной дифференциацией и кнопкой очистки логов.

### 4. ✍️ Студия Автора («Author Studio»)
- **Полноценный конструктор учебных дисциплин**:
  - Управление деревом курса, модулями и главами.
  - Редактор метаданных (код, название, описание, теги, время чтения).
  - Динамический визуальный конструктор секций контента (текст, код с выбором языка и файла, цитаты-callout).
  - Конструктор карточек 3D Active Recall и проверочных экспресс-квизов.
  - Live Preview в реальном времени с синхронизацией редактирования.
- **Экспорт и Импорт курсов в JSON**:
  - Экспорт выбранного курса или полного бэкапа всех курсов в один клик.
  - Модальное окно импорта с поддержкой drag-and-drop, вставкой сырого JSON, валидацией схемы, интерактивным предпросмотром структуры и стратегиями разрешения коллизий (создание копии vs перезапись).

### 5. 🎓 Личный Кабинет Студента («Cabinet Dashboard»)
- **Сводная панель успеваемости**: уровень пользователя, общий накопленный опыт (XP), прогресс-бар до следующего ранга, счетчики завершенных глав и выученных флешкарт.
- **Матрица стриков активности GitHub-style (`UiActivityCalendar`)**:
  - Сетка 26/52 недель с 7 днями, 4 уровнями интенсивности, цветовыми схемами (`Green`, `Indigo`, `Amber`, `Cyan`) и плавающим тултипом с локализованной датой и списком событий.
- **Интерактивный график набора опыта (`UiXpChart`)**:
  - Плавная кривая Безье (SVG Spline) с градиентной заливкой Area и переключателем в столбчатый режим (Bar Chart), линия перекрестья crosshair и панель KPI.
- **Практические задания и лабораторные работы (`CabinetAssignmentsTab`)**:
  - Карточки работ (лабораторные, проекты, тесты) со статусами («К сдаче», «На проверке», «Принято», «Доработка»).
  - Модалка сдачи решений (Git-репозиторий или редактор кода) и модалка проверки ментором.
- **Закладки и заметки (`CabinetNotesTab`)**: реестр сохраненных страниц пергамента и карточек заметок на полях.
- **Динамические достижения (`CabinetAchievementsTab`)**: расчет наград в реальном времени на основе реального прогресса в сторах.

### 6. 👑 Панель Администратора («Admin Dashboard»)
- **Управление пользователями (`admin-users-tab`)**: реестр студентов и авторов с аватарами, уровнями, сменой ролей в 1 клик (`Студент`, `Автор`, `Преподаватель`, `Администратор`, `Гость`) и блокировкой учетных записей.
- **Модерация курсов (`admin-courses-tab`)**: реестр дисциплин с переключением публикации (`Опубликован` ↔ `Черновик`), быстрым переходом в ридер и удалением.
- **Аналитика платформы (`admin-analytics-tab`)**: метрики вовлеченности, динамика активности за неделю и распределение дисциплин по стеку.
- **Системные настройки (`admin-settings-tab`)**: управление регистрацией, режимом обслуживания и сброс демо-данных.

### 7. 🔍 Командная Палитра & Spotlight-поиск (`Ctrl + K`)
- Глобальное модальное окно быстрого поиска по нажатию `Ctrl + K` / `Cmd + K` или клику в шапке.
- Поиск по всем курсам, модулям, статьям справочника и системным разделам платформы.
- Клавиатурная навигация `↑` / `↓` и мгновенный переход по нажатию `Enter`.

### 8. 🔔 Центр Уведомлений и Всплывающие Тосты
- **Плавающие Toast-уведомления** (`ToastContainer`) в правом верхнем углу с авто-скрытием и типами (`success`, `info`, `warning`, `error`).
- **Колокольчик в шапке** со светящимся бейджем непрочитанных и выпадающим поповером (`NotificationPopover`) с фильтрами («Все» / «Непрочитанные»), действиями («✓ Все прочитаны», «Очистить») и переходами к событиям.
- Интеграция с ключевыми действиями: закладки, заметки на полях, завершение глав и сдача заданий.

### 9. 🎨 Дизайн-система & Мультитемность
- **Палитры оформления**:
  - `Bookish Codex` (фирменный пергамент с золотыми и теплыми акцентами),
  - `Ocean Dark` (глубокий сине-киберпанковый градиент),
  - `Mindful Sage` (академический шалфей и изумруд),
  - `Default` (лаконичная современная темная тема).
- **Shared UI Kit**: `UiButton`, `UiCard`, `UiBadge`, `UiInput`, `UiBanner`, `UiPopover`, `UiDateInput`, `UiActivityCalendar`, `UiXpChart`, `InteractiveFlashcard`.
- Интерактивная витрина компонентов доступна по маршруту `/ui-kit`.

### 10. 🗄️ Backend & Облачная База Данных Supabase
- Микросервис на **Node.js + Express + TypeScript** (`projects/Back`) на порту 5000.
- Облачная база данных **PostgreSQL в Supabase** (`gywehqprnrnxqxtxskyf.supabase.co`).
- Настроена безопасность Row Level Security (RLS), разделение публичного и сервисного клиентов (`supabaseAdmin`).
- JWT-авторизация, хэширование паролей солью (bcryptjs), RBAC-контроль доступа.
- Полная синхронизация фронтенда через `DocHttpRepository`, `DocProgressApiService`, `UserApiService` с автоматическим fallback на локальное хранилище при отсутствии связи.

### 11. 🧪 Сквозное Unit-Тестирование (Jest)
- Инфраструктура тестов на базе **Jest**, `ts-jest` и `jest-environment-jsdom`.
- Написаны и проходят со 100% успехом **22 теста** в `tests/unit/`:
  - `tests/unit/adapters/course-transfer.spec.ts` — парсинг, валидация и коллизии курсов.
  - `tests/unit/services/code-runner.spec.ts` — стриппер TypeScript и исполнение кода.
  - `tests/unit/stores/notification-store.spec.ts` — стор уведомлений и тостов.
  - `tests/unit/stores/doc-progress-store.spec.ts` — прогресс, начисление XP, уровни и тесты.

## 🏗 Архитектура — Feature-Sliced Design (FSD)

```
src/
├── app/               # Инициализация приложения, роутер, глобальные стили, layout
│   ├── providers/     # Pinia, Vue Router
│   ├── styles/        # CSS-переменные тем, токены, сброс стилей
│   └── App.vue        # Корневой Shell с монтированием модалок и тостов
│
├── pages/             # Маршрутные страницы
│   ├── home/          # Главный промо-экран
│   ├── courses/       # Каталог учебных курсов
│   ├── docs/          # Чииталка Bookish Codex
│   ├── author/        # Студия автора и конструктор
│   ├── cabinet/       # Личный кабинет студента
│   ├── admin/         # Панель администратора
│   ├── auth/          # Авторизация и регистрация
│   └── ui-kit/        # Интерактивная витрина компонентов
│
├── widgets/           # Крупные самодостаточные UI-блоки
│   ├── app-header/    # Навигационная шапка с темой, поиском, колокольчиком
│   ├── docs-viewer/   # Дерево, пергаментная статья, Study Deck
│   ├── author-studio/ # Сайдбар курса, редактор контента, Live Preview
│   ├── cabinet-dashboard/ # Вкладки ЛК (обзор, активность, задания, заметки, ачивки)
│   └── admin-dashboard/   # Вкладки администрирования
│
├── features/          # Пользовательские сценарии и взаимодействия
│   ├── command-palette/   # Быстрый поиск Ctrl+K
│   ├── code-playground/   # Интерактивная веб-песочница
│   ├── notification-center/ # Тосты и поповер колокольчика
│   ├── deck-trainer/      # Полноэкранный 3D тренажер памяти
│   └── rate-doc/          # Оценка полезности статьи
│
├── entities/          # Бизнес-сущности предметной области
│   ├── doc/           # Курсы, модули, главы, репозитории, стор заметок и прогресса
│   ├── user/          # Пользователь, сессия, роли RBAC
│   ├── course/        # Модели практических заданий и лабораторных
│   └── notification/  # Модели и стор уведомлений
│
├── shared/            # Переиспользуемый базис (без бизнес-логики)
│   ├── ui/            # UI Kit (кнопки, баннеры, инпуты, поповеры)
│   ├── api/           # HTTP-клиент, конфигурация эндпоинтов, JWT-заголовки
│   └── lib/           # Web Audio синтезатор звуков, утилиты
│
└── projects/Back/     # Серверный REST API микросервис (Node.js + TypeScript + Supabase)
```

## 💻 Стек технологий

| Категория | Технологии |
|---|---|
| **Frontend Framework** | Vue 3 (Composition API, `<script setup lang="ts">`) |
| **Язык разработки** | TypeScript 5.0+ (строгая типизация DTO, интерфейсов и сторов) |
| **Стейт-менеджмент** | Pinia 2 |
| **Маршрутизация** | Vue Router 4 |
| **Стилизация** | SCSS, CSS Custom Properties (дизайн-токены, мультитемность) |
| **Аудио-движок** | Web Audio API (нативный процедурный синтез звуков) |
| **Тестирование** | Jest, ts-jest, jest-environment-jsdom |
| **Бэкенд** | Node.js 22, Express, TypeScript, tsx, CORS |
| **База данных** | Supabase Cloud (PostgreSQL) + Prisma ORM (SQLite для локального режима) |
| **Безопасность** | JWT (JSON Web Tokens), bcryptjs, Row Level Security (RLS) |

## 🛠 Запуск и разработка

### 1. Установка зависимостей
```bash
# В корне фронтенда (lern_host)
npm install

# В директории бэкенда (projects/Back)
cd projects/Back
npm install
cd ../..
```

### 2. Запуск бэкенда (Node.js + Supabase)
```bash
cd projects/Back
npm run dev
# Сервер запустится на http://localhost:5000
```

### 3. Запуск фронтенда
```bash
npm run serve
# Приложение доступно на http://localhost:1000
```

### 4. Запуск Unit-тестов
```bash
npm run test:unit
# Запуск 22 сквозных тестов Jest
```

### 5. Production-сборка
```bash
npm run build
# Сборка в папку dist/learning_platform_1.0.0
```
